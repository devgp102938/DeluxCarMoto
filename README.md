# DeluxCarMoto
A responsive multi-page luxury car showcase website with brand navigation and a JavaScript-based Dom manipulation and Form validation test drive booking system, built with a focus on clean UI, responsiveness, and interactivity.

### 🔹 Project Overview
DeluxCarMoto is a fully responsive luxury car showcase platform that highlights premium car brands with smooth navigation and a modern user interface. The project includes a complete JavaScript-based **Test Drive Booking System** with proper form validation to ensure a realistic user experience.

### 🔹 Key Features
- Multi-page website structure  
- Responsive design for desktop, tablet, and mobile devices  
- Luxury car brand navigation  
- JavaScript-powered test drive booking form  
- Client-side form validation  
- Clean and user-friendly UI  

### 🔹 Tech Stack
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

### 🔹 Purpose
This project was developed as part of my BCA coursework to strengthen frontend development skills and understand real-world UI behavior, responsiveness, and form handling using JavaScript.
